# Archivos de Audio para GlaciAgua

Esta carpeta contiene las grabaciones de audio accesibles para personas con baja alfabetización en la Cordillera Blanca:

- `es/`: Audios en español neutro / andino claro.
- `qu/`: Audios en quechua ancashino (variedad Callejón de Huaylas).

## Nombres esperados de archivo:
- `bienvenida.mp3`: Explicación en 3 pasos de qué es GlaciAgua.
- `estado_agua.mp3`: Explicación del semáforo actual.
- `aviso_hervir.mp3`: Advertencia crítica de que hervir el agua no elimina los metales pesados.
- `quebrada_quillcay.mp3`: Audio explicativo para la cuenca Quillcay.
- `quebrada_pachacoto.mp3`: Audio explicativo para la cuenca Pachacoto.
- `quebrada_canray.mp3`: Audio explicativo para Canray Chico.
- `quebrada_rioblanco.mp3`: Audio explicativo para Río Blanco.
- `reportar_guia.mp3`: Instrucciones paso a paso para avisar de agua turbia o con metales.

Si un archivo no existe, el sistema utiliza síntesis de voz del navegador únicamente en español, y oculta el botón en quechua hasta que se grabe con hablantes nativos.
