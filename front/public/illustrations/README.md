## Especificaciones Técnicas
- **Formato**: SVG optimizado o WebP (< 60 KB).
- **Animaciones**: Micro-animaciones CSS embebidas con soporte automático de `@media (prefers-reduced-motion: reduce)`.
- **Reemplazo con otra herramienta**: Puedes reemplazar cualquiera de estos archivos colocando tu versión con el **mismo nombre exacto** dentro de esta carpeta. Los componentes los cargarán automáticamente.
